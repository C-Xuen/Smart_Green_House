## 三、嵌入式软件层设计

### 3.1 RTOS 任务表

| 任务名 | 入口函数 | 优先级 | 栈 | 周期 | 职责 |
|--------|---------|--------|-----|------|------|
| WiFi | `wifi_task_func` | High (13) | 8KB | 一次性 | DHCP 获取 IP |
| HTTP | `http_server_task` | 18 | 8KB | 事件驱动 | 3 个 REST API |
| MQTT | `mqtt_task` | Normal | 12KB | 5s | 数据上报华为云 |
| LED | `led_control_task` | Normal | 4KB | 10ms | 呼吸灯 / 频闪 |
| SGH | `sgh_task` | 17 | 4KB | 100ms | 传感器+OLED+告警 |
| Button | `button_task` (内部) | 18 | 1KB | 10ms | GPIO 扫描消抖 |

### 3.2 传感器信号采集

| 传感器 | 接口类型 | 协议/参数 | 读取方式 | 更新频率 |
|--------|---------|----------|---------|---------|
| DHT11 温湿度 | 单总线 GPIO | 自定义时序 40bit | 主机拉低 20ms 启动 | 1s |
| JW01 CO2 | UART2 | 9600-8N1, 6B 帧 | 被动接收 `0x2C` 帧头 | ~800ms |
| 土壤湿度 | ADC CH2 | 12bit, 500KHz | 自动扫描 + 回调 | 100ms |
| 光敏电阻 | ADC CH3 | 同上 | 同上 | 100ms |
| 火焰 | GPIO 输入 | 高低电平 | 轮询 | 100ms |
| 按键×3 | GPIO 输入 | 下降沿检测 | 独立任务 10ms 扫描 | 10ms |

**计算公式**：
- 土壤湿度% = `ADC_CH2 × 100 / 3300`
- 光照强度% = `(3300 − ADC_CH3) × 100 / 3300`
- CO2 ppm = `frame[1] × 256 + frame[2]`

### 3.3 告警分级逻辑

```
火焰检测 → 蜂鸣器 + 风扇 + 水泵全开（5 秒恢复延时）
CO2 超标 或 温湿度超标 → 蜂鸣器 + 风扇
其他单阈值超标 → 蜂鸣器
光照 < 阈值 → 补光灯（迟滞±10 防闪烁）
```

### 3.4 数据持久化

- **NV (Non-Volatile) 存储**：阈值写入 key `0x8001`，掉电不丢失
- **阈值同步**：网页 → HTTP → 设备 NV，OLED 实时读取，MQTT 上传云端

## 四、云平台属性连接

### 4.1 MQTT 认证

| 参数 | 值 |
|------|-----|
| Broker | `tcp://049a9b92ef.iotda-device.cn-south-4.myhuaweicloud.com:1883` |
| ClientId | 参数生成工具获取 |
| Username | `{设备ID}_H3863` |
| Password | 参数生成工具获取（64 位 Hex） |
| 库 | Paho MQTT C Client + `MQTTClient_init()` 前置调用 |

### 4.2 上报 Topic

```
$oc/devices/{device_id}/sys/properties/report
```

### 4.3 产品模型属性（华为云 IoTDA 需定义）

| 属性名 | 类型 | 范围 | 说明 |
|--------|------|------|------|
| `temperature` | decimal | 0~60 | 空气温度 ℃ |
| `humidity` | decimal | 0~100 | 空气湿度 % |
| `co2` | int | 0~5000 | CO2 浓度 ppm |
| `soil_moisture` | int | 0~100 | 土壤湿度 % |
| `light` | int | 0~100 | 光照强度 % |
| `flame` | int | 0/1 | 火焰检测 |
| `th_temp` | int | 0~60 | 温度阈值 |
| `th_humi` | int | 0~100 | 湿度阈值 |
| `th_co2` | int | 0~5000 | CO2 阈值 |
| `th_soil` | int | 0~100 | 土壤下限阈值 |
| `th_light` | int | 0~100 | 光照下限阈值 |

### 4.4 上报 JSON 格式

```json
{
  "services": [{
    "service_id": "smart_green_house",
    "properties": {
      "temperature": 27.5,
      "humidity": 49.2,
      "co2": 450,
      "soil_moisture": 48,
      "light": 65,
      "flame": 0,
      "th_temp": 35,
      "th_humi": 85,
      "th_co2": 1200,
      "th_soil": 60,
      "th_light": 5
    }
  }]
}
```

### 4.5 设备 API（H3863 server.c 端口 80）

| 方法 | 路径 | 数据 | 说明 |
|------|------|------|------|
| GET | `/api/temp_humi` | JSON | 传感器 + 阈值全量数据 |
| POST | `/api/control` | `{device, status}` | 控制风扇/水泵/补光灯 |
| POST | `/api/threshold` | `{temp_max, ...}` | 设置阈值 |

## 五、应用层设计

### 5.1 Flask 网页 (app.py)

**启动**：
```bash
pip install flask requests
python app.py         # 监听 0.0.0.0:5000
```

**数据源**：华为云 IoTDA 设备影子（IAM 鉴权）

**API 端点**：

| 端点 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 渲染仪表盘 HTML |
| `/api/data` | GET | 传感器实时数据 |
| `/api/history` | GET | 温湿度历史（30 条） |
| `/api/alarms` | GET | 告警记录 |
| `/api/threshold` | GET/POST | 读/写阈值，POST 转发到 H3863 |
| `/api/control` | POST | 设备控制，转发到 H3863 |

**网页功能**：
- 5 个传感器卡片（温度/湿度/CO2/光照/土壤）+ 火焰指示
- 5 个 ECharts 独立历史曲线（2×2+1 网格）
- 3 个滑动开关（风扇/补光灯/水泵）+ 平滑动画
- 5 行阈值设置（每行独立保存按钮）+ OLED 双向同步
- 告警记录列表
- 设备连接状态指示

### 5.2 微信小程序 (Weapp/)

**启动**：微信开发者工具 → 导入 `src/Weapp/` → AppID 测试号

**本地调试**：
- `index.js` 中 `useCloud: false`，`API_BASE` 填 PC 局域网 IP
- 勾选「不校验合法域名」

**功能**：传感器卡片 + 阈值控制 + 设备开关（与网页 UI 一致）

### 5.3 跨设备访问

| 访问方式 | 地址 | 条件 |
|---------|------|------|
| 本机 | `http://127.0.0.1:5000` | Flask 运行即可 |
| 局域网 | `http://<PC_IP>:5000` | 同 WiFi |
| 外网 | ngrok 穿透 / 云服务器部署 | 需公网服务 |

## 七、注意事项

- DHT11 严格时序，高优先级中断可能影响读取成功率
- JW01 上电需 2-3 分钟数据稳定
- 华为云 ClientId 含时间戳，有效期约 24 小时，需用参数工具定时刷新
- 风扇/水泵/补光灯 GPIO 为低电平有效（NPN/MOS 驱动）
- GPIO_02 为蜂鸣器与绿色 LED PWM 复用，SGH 任务与 LED 任务互斥控制
